# World of Albion Bot 🤖

Bot de Discord para **organizar grupos y eventos** en **Albion Online**.

## 🚀 Características

- ✅ Sistema de eventos (Dorados, Zona Abierta, Avas, Cta, Arenas, etc)
- ✅ Roles con selectores interactivos
- ✅ Canales de voz automáticos
- ✅ Whitelist de servidores
- ✅ 24/7 en la nube

## 🛠️ Tecnologías

- **Discord.js v14**
- **Node.js 20**
- **Fly.io** (despliegue 24/7)
- **Docker** (contenedor ligero)
